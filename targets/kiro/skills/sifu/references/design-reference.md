# Design Guidance: reference

What `design-author` populates for a `reference` skill. Rules live in
`reference-conventions.md`.

- `sections` — one per rule category or band of guidance.
- `files` — usually empty; add a reference file only when a rule body is
  too long for SKILL.md or has independent reuse value.
- `tasks` — empty.
- `rationale` — at most ~5 bullets: rule scope, prescriptiveness,
  alternatives rejected.
