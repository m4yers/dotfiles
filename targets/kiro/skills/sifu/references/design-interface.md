# Design Guidance: interface

What `design-author` populates for an `interface` skill. Rules live in
`interface-conventions.md`.

- `sections` — the sections interface-conventions requires (Invocation,
  API, Commands, branches).
- `files` — one reference file per branch, plus example pages.
- `tasks` — empty.
- `rationale` — at most ~5 bullets: surface area, branching strategy,
  alternatives rejected.
